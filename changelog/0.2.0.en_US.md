# Stein Client 0.2.0: a single executable

The launcher now updates itself, with no second program involved.

- **A single executable**: `SteinClient.exe` downloads its own new version, swaps the file and reopens. `SteinUpdater.exe` no longer exists.
- **If you have an earlier version** (0.1.0 to 0.1.2), download `SteinClient.exe` again, once: those versions relied on the updater to update. Accounts, mods, worlds and settings stay as they are.
- **From now on**, updates arrive by themselves when you open the launcher.
