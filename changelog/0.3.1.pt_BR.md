# Stein Client 0.3.1: downloads no repositório do próprio código

O Stein Client e tudo o que ele baixa agora vêm dos repositórios onde fica o código de cada um.

- **Um lugar novo para os downloads**: o Stein Client se atualiza a partir de [Stein-Project/client](https://github.com/Stein-Project/client/releases) e baixa o Stein Loader e o Java de [Stein-Project/installer](https://github.com/Stein-Project/installer/releases).
- **Atualiza sozinho**: um launcher 0.3.0 passa para esta versão por conta própria na próxima vez que abrir. Nada muda no jeito de entrar ou de jogar.
