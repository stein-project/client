# Stein Client 0.3.3: signed information and developer options

The launcher now gets everything it needs to know from one signed source, and it can be adjusted without a new version.

- **Signed information**: the latest version of the pack and of the official mods, the game's memory, the menu links and the launcher's own updates now come from the Stein registry, signed. The launcher refuses anything changed on the way and keeps the last good copy when the internet is down.
- **Settings for specific graphics cards**: when a card needs a different Java setting to run well, the launcher applies it by itself.
- **Broken or harmful mods stopped**: a mod known to be broken or harmful is not downloaded or installed.
- **Developer options**: in Settings, you can turn on log topics when someone asks for a log to fix a problem, and add Java arguments. Only safe arguments are accepted, so a "paste this for more FPS" line cannot run anything on your computer.
