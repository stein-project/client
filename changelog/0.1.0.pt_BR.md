# Stein Client 0.1.0: o launcher oficial do Stein

A primeira versão do Stein Client, o launcher do Minecraft 1.8.9 com o Stein Loader e os mods oficiais, pronto para jogar. Baixe o `SteinClient.exe`, deixe onde preferir, execute e entre com a sua conta Microsoft.

- **Instalação automática**: baixa o Minecraft direto da Mojang em `%APPDATA%\.steinclient`, junto com o Stein Loader, o Java e os mods.
- **Sempre atualizado**: a cada abertura, o launcher confere se há versão nova dele e se atualiza; o Loader, o Java e os mods são atualizados ao clicar em Jogar.
- **Conta Microsoft**: entrada por código, pelo navegador, com suporte a várias contas. O jogo só abre com uma conta que possui o Minecraft: Java Edition.
- **Contas offline**: com uma conta original no launcher, você pode criar nicks offline para jogar sozinho ou em servidores sem autenticação.
- **Mods oficiais**: escolha quais usar; eles são baixados e atualizados ao clicar em Jogar.
- **Atualizações à vista**: antes de jogar, o launcher mostra o que vai ser instalado, atualizado ou removido, com as versões.
- **Recuperação de falhas**: se o jogo fechar por um erro, o launcher volta com o log, o Discord do Stein Labs e a opção de reiniciar com os logs do Stein ativos.
- **Portátil**: um arquivo vazio chamado `portable` ao lado do `SteinClient.exe` mantém tudo naquela pasta.
