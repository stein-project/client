# Stein Client 0.1.0: the official Stein launcher

The first release of the Stein Client, the Minecraft 1.8.9 launcher with the Stein Loader and the official mods, ready to play. Download `SteinClient.exe`, keep it wherever you like, run it and sign in with your Microsoft account.

- **Automatic setup**: downloads Minecraft straight from Mojang into `%APPDATA%\.steinclient`, along with the Stein Loader, Java and the mods.
- **Always up to date**: every time it opens, the launcher checks for a new version of itself and updates; the Loader, Java and the mods are updated when you click Play.
- **Microsoft account**: sign in with a code in the browser, with support for multiple accounts. The game only starts with an account that owns Minecraft: Java Edition.
- **Offline accounts**: with an original account in the launcher, you can create offline nicknames for singleplayer or servers without authentication.
- **Official mods**: choose which ones to use; they are downloaded and updated when you click Play.
- **Clear updates**: before you play, the launcher shows what will be installed, updated or removed, with the versions.
- **Crash recovery**: if the game closes because of an error, the launcher comes back with the log, the Stein Labs Discord and the option to restart with Stein logs enabled.
- **Portable**: an empty file named `portable` next to `SteinClient.exe` keeps everything in that folder.
