# Stein Client 0.3.0: open source

The Stein Client is now open source, under the Mozilla Public License 2.0. Anyone can read how it signs in, what it
downloads and how it starts the game.

- **Open source**: the code is at [github.com/Stein-Project/client](https://github.com/Stein-Project/client), like the
  Stein Loader, the Stein Bridge and the official mods.
- **Download it again**: launchers up to 0.2.9 do not update to this version on their own. Download the new
  `SteinClient.exe` once; from here on it keeps itself up to date.
- **Offline accounts always confirmed**: playing with an offline nick always confirms the original account in the
  launcher first, with no exceptions.
- **Cleaner**: test-only options and the unreleased Profiles page were removed.
