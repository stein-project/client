# Stein Client 0.3.0: código aberto

O Stein Client agora tem código aberto, sob a Mozilla Public License 2.0. Qualquer um pode ver como ele entra na conta,
o que baixa e como abre o jogo.

- **Código aberto**: o código está em [github.com/Stein-Project/client](https://github.com/Stein-Project/client), como o
  do Stein Loader, do Stein Bridge e dos mods oficiais.
- **Baixe de novo**: os launchers até a 0.2.9 não se atualizam sozinhos para esta versão. Baixe o `SteinClient.exe`
  novo uma vez; daqui para frente ele se mantém atualizado.
- **Contas offline sempre conferidas**: jogar com um nick offline sempre confirma antes a conta original do launcher,
  sem exceção.
- **Mais enxuto**: saíram as opções só de teste e a página de Perfis, que ainda não tinha sido lançada.
