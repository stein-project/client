# Stein Client 0.2.0: um executável só

O launcher agora se atualiza sozinho, sem precisar de um segundo programa.

- **Um executável só**: o `SteinClient.exe` baixa a própria versão nova, troca o arquivo e reabre. O `SteinUpdater.exe` deixou de existir.
- **Quem tem uma versão anterior** (0.1.0 a 0.1.2) precisa baixar o `SteinClient.exe` novamente, uma única vez: aquelas versões dependiam do updater para se atualizar. Contas, mods, mundos e configurações continuam como estão.
- **Daqui em diante**, as atualizações chegam sozinhas ao abrir o launcher.
