# Stein Client 0.3.1: downloads from their own repository

The Stein Client and everything it downloads now come from the repositories where their code lives.

- **A new home for the downloads**: the Stein Client updates itself from [Stein-Project/client](https://github.com/Stein-Project/client/releases), and downloads the Stein Loader and Java from [Stein-Project/installer](https://github.com/Stein-Project/installer/releases).
- **Updates on its own**: a 0.3.0 launcher moves to this version by itself the next time it opens. Nothing changes in how you sign in or play.
