# Stein Client 0.2.9: direto para a última versão

O Stein Client agora se atualiza até a última versão numa abertura só.

- **Atualização de uma vez**: quando o Stein Client se atualiza, a versão nova confere de novo ao abrir e segue até chegar na última. Um launcher várias versões atrás chega lá numa abertura só, em vez de uma versão por vez a cada vez que você abre.
