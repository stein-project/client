# Stein Client 0.3.4: choose the graphics API, with Vulkan by default

The launcher opens the game with Vulkan, and you can switch to OpenGL whenever you want.

- **Graphics API in Settings**: choose between Vulkan and OpenGL; the change applies the next time the game opens.
- **Vulkan by default**: the game opens with Vulkan, which gives more FPS on most graphics cards.
- **Back to OpenGL by itself**: if Vulkan closes the game while it opens on your computer, the launcher opens the game again with OpenGL right away and tells you what happened.
