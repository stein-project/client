# Stein Client 0.1.2: fewer false antivirus alerts

The launcher is now built in a different way, which reduces false alerts from some antivirus software. Nothing changes in how you use it.

- **Fewer false positives**: the executable is no longer squeezed to the smallest size, which made some antivirus software mistake it for a suspicious file. In exchange, it is larger (about 14 MB).
- **Automatic update**: if you already have the launcher, this version installs itself when you open it.
