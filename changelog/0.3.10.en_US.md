# Stein Client 0.3.10: the game log is no longer lost

Whoever needs to send the log of a problem now finds the right session, even after opening the game again.

- **Every session's log kept**: before the game opens, the launcher keeps the previous `game.log` in a `.zip` file in `logs/stein-client`, with the date in its name. Before, every start deleted the previous one.
- **Launcher logs no longer grow forever**: when `launcher.log` or `installer.log` pass 1 MB, they go into the same kind of file and start over.
- The 200 newest files are kept; older ones are deleted.
