# Stein Client 0.2.5: Stein GFX on

The game opened by the Stein Client now uses Stein GFX, Stein's new renderer.

- **Stein GFX by default**: the Stein Client opens the game with the new renderer on. F3 shows which one is drawing.
- **Graphics card without OpenGL 4.1**: if the game cannot open with Stein GFX for lack of OpenGL 4.1, the Stein Client opens it again right away with the usual renderer, and remembers that next time.
