# Stein Client 0.3.4: escolha da API gráfica, com o Vulkan por padrão

O launcher abre o jogo com o Vulkan, e você pode trocar para o OpenGL quando quiser.

- **API gráfica nos Ajustes**: escolha entre Vulkan e OpenGL; a troca vale a partir da próxima abertura do jogo.
- **Vulkan por padrão**: o jogo abre com o Vulkan, que dá mais FPS na maioria das placas.
- **Volta sozinho para o OpenGL**: se o Vulkan fechar o jogo ao abrir no seu computador, o launcher abre o jogo de novo com o OpenGL na mesma hora e avisa o que aconteceu.
