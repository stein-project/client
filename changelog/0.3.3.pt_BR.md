# Stein Client 0.3.3: informações assinadas e opções de desenvolvedor

O launcher agora recebe tudo o que precisa saber de uma fonte assinada, e pode ser ajustado sem uma versão nova.

- **Informações assinadas**: a versão mais nova do pacote e dos mods oficiais, a memória do jogo, os links do menu e as atualizações do próprio launcher agora vêm do registro do Stein, assinado. O launcher recusa qualquer coisa alterada no caminho e guarda a última cópia boa para quando a internet cai.
- **Ajustes para placas de vídeo específicas**: quando uma placa precisa de uma configuração diferente do Java para rodar bem, o launcher aplica sozinho.
- **Mods quebrados ou perigosos barrados**: um mod conhecido por estar quebrado ou ser perigoso não é baixado nem instalado.
- **Opções de desenvolvedor**: em Configurações, você pode ligar os assuntos do log quando alguém pedir um log para resolver um problema, e acrescentar argumentos do Java. Só argumentos seguros são aceitos, então uma linha do tipo "cole isto para ganhar FPS" não consegue rodar nada no seu computador.
