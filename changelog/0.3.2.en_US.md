# Stein Client 0.3.2: choose the portable install's folder

A portable install can now keep the launcher alone in its folder and the game in a subfolder of your choice.

- **Folder in the `portable` file**: write a path in the `portable` file next to `SteinClient.exe`, such as `data\.steinclient`, and the game, Java, mods, worlds and settings go to that folder, relative to the launcher's. An empty `portable` file keeps everything next to the launcher, as before.
- **Any way you save it**: the file works whether it was saved by Notepad or PowerShell, and with the quotes Explorer adds when you copy a path.
- **If your `portable` file already has text in it**: that text is now read as the folder. Empty it to keep using the launcher's folder.
